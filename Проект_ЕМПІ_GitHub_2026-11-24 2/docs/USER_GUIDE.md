# Інструкція користувача

## Реєстрація студента або викладача

1. На сторінці входу натисніть «Створити обліковий запис».
2. Укажіть ім’я та прізвище, електронну пошту й виберіть роль.
3. Придумайте пароль із 12–128 символів і повторіть його в полі підтвердження.
4. Натисніть «Зареєструватися». Після підтвердження створення увійдіть із власним паролем. Поле пошти вже буде заповнене.
5. Зверніться до адміністратора для призначення курсів і навчальної групи. Нові користувачі з’являються в адміністративному розділі «Користувачі».

## Студент

1. Увійдіть зі своєю електронною поштою та паролем.
2. Відкрийте «Завдання», відфільтруйте за дисципліною й виберіть питання.
3. Введіть текст і натисніть «Надіслати відповідь». Система підтвердить збереження та відкриє картку подання.
4. Перегляньте результат і рішення викладача в «Моїх відповідях». Момент показу автоматичного результату залежить від параметрів курсу.

## Викладач

1. Відкрийте «Банк питань» і створіть питання для призначеного курсу.
2. Заповніть щонайменше два різні еталони. У новій формі вже є два блоки; копії одного тексту не приймаються. Для понять задайте синоніми, вагу й обов’язковість. За наявності типових помилок додайте фразу й пояснення правила.
3. Опублікуйте питання. У «Дисциплінах» можна налаштувати видимість результатів, пороги курсу й зарахування студентів за ID, наданими адміністратором.
4. У «Перевірці відповідей» відкрийте подання. Розгорніть «Розрахунок і порівняння еталонів», щоб побачити зіставлення з усіма кандидатами й підстановку чисел у формулу. Сторінка «Методика перевірки» містить першоджерела. Виберіть власне рішення й збережіть коментар. Для старого результату можна натиснути «Повторити аналіз»; історія зберігається.
5. Для правильної відповіді за потреби позначте «Зберегти як затверджену варіацію». У «Базі варіацій» можна переглянути пропозиції, затвердити, відхилити або архівувати формулювання.
6. «Історія» в картці відповіді показує окремі версії аналізу й рішень. Після помилки скористайтеся кнопкою «Повторити аналіз».
7. На сторінці «Огляд» стовпчиковий графік «Точність відповідей студентів» показує відсоток повністю правильних відповідей серед перевірених за кожен день надсилання. Ураховується останнє рішення викладача; частково правильні входять лише до загальної кількості перевірених. Дні без рішень залишаються пропусками. Виберіть дисципліну й період, наведіть курсор на стовпчик для деталізації або відкрийте «Дані графіка». Загальний відсоток над графіком розраховано за всіма перевіреними відповідями в межах показаних днів.

У версії аналізу 3.0.0 сторонній текст без підтвердженого зв’язку з еталонами отримує **0%**.
У картці роботи викладач бачить початкову подібність B, перевірку зв’язку G та підсумок F для
кожного еталона. Сторінка «Методика перевірки» пояснює правило й джерела. Якщо показано попередню
версію аналізу, натисніть «Повторити аналіз». Історія й ручні рішення зберігаються.

## Адміністратор

1. Створіть спеціальність, дисципліну й навчальну групу у «Довідниках».
2. Створіть користувачів і призначте їм ролі. У картці кожного курсу призначте відповідного викладача та зарахуйте студентів. У демонаборі вже є сім окремих викладачів дисциплін; їхні логіни наведені в README. Студенти бачать імена викладачів у списку й картці дисципліни.
3. У «Налаштуваннях NLP» перевірте сигнал воркера, модель та параметри класифікації. Перевіряйте пороги на корпусі з викладацькою розміткою.
4. Використовуйте «Журнал аудиту» для перегляду змін. Для обмеження доступу відкличте зарахування, призначення викладача або заблокуйте обліковий запис.
